# نموذج أولي: الشهادة العربية (HTML→PDF و DOCX→PDF)

**الهدف:** التأكد من أن توليد شهادات عربية (RTL، اتصال الحروف، أرقام وتواريخ لاتينية، جدول، QR) يعمل بجودة مقبولة، وأنه يعمل على **ARM64** كما في سيرفر Oracle، قبل اعتماد المسار في المرحلة 6.

## التشغيل (على السيرفر ARM64 أو أي جهاز فيه Docker)
```bash
cd spikes/arabic-certificate
sh run-docker.sh      # يطبع في النهاية معمارية الجهاز (aarch64 على ARM64)
```
الناتج في `out/`: `certificate.html.pdf` و`certificate.docx.pdf` وصورتا PNG لكل منهما، وفي الطرفية أسماء الخطوط المضمّنة وأزمنة التوليد.

للتشغيل بدون Docker: `npm install && python3 scripts/make_docx_template.py && node scripts/render.mjs` (يحتاج chromium وlibreoffice-writer وpoppler-utils ويُسجَّل خطا Amiri وNoto Naskh).

## ماذا نفحص بصرياً في الناتج
1. اتصال الحروف سليم (لا حروف مفصولة أو معكوسة).
2. التواريخ تظهر `2026-10-04` وليس `04-10-2026`، والأرقام الطويلة والأكواد (`HR-2026-000123`) سليمة الاتجاه.
3. الجدول والمحاذاة إلى اليمين، والشدّة والتشكيل (عمّان).
4. رمز QR ظاهر ويُمسح (في نسخة HTML).
5. الخطوط المضمّنة (`pdffonts`) هي Amiri/Noto Naskh وليست خطاً بديلاً.

## النتائج على بيئة التطوير (x86_64 / Ubuntu 24.04)
| | HTML→PDF (Chromium) | DOCX→PDF (LibreOffice) |
|---|---|---|
| اتصال الحروف والتشكيل | ممتاز | ممتاز |
| الزمن | ~0.5–1.2 ث | ~1.1–1.7 ث |
| التحكم بالتصميم | كامل (CSS) | جيد (حسب قالب Word) |
| QR | يعمل (data URL) | غير مضاف (يحتاج وحدة صور مدفوعة في docxtemplater أو docx-templates) |
| نص PDF القابل للنسخ/البحث | يعمل مع فواصل غريبة بين بعض الحروف | رموز غريبة في بعض الحروف (من ميزات خط Amiri) |

## ما اكتُشف (يُدمج في المرحلة 6)
1. **اتجاه الأرقام في DOCX:** التواريخ والأكواد اللاتينية داخل فقرة RTL تنعكس (`2026-10-04` ← `04-10-2026`). الحل: تغليف القيم اللاتينية بـ **LRI/PDI** (`U+2066…U+2069`) قبل التعبئة. جُرّبت LRE وLRM: LRE تصحح الاتجاه لكن قد تنكسر القيمة بين سطرين (`201` / `9-03-01`)، وLRM لا تكفي. **يجب اختبار LRI داخل Microsoft Word نفسه**؛ إن لم يدعمها فالبديل LRE.
2. **محاذاة DOCX:** عدم ضبط `jc` في فقرات `bidi` يعني بداية السطر (اليمين)، أما `jc=right` فينقلب إلى اليسار.
3. **الخطوط:** تُضمَّن مع المشروع (OFL) وتُسجَّل في الحاوية، ويحملها HTML بـ `@font-face` بمسار نسبي. لا تعتمد على خطوط النظام.
4. **القوالب:** يجب ألا تُقسَّم متغيرات `{name}` على أكثر من run في Word (تعطل docxtemplater)؛ يُوصى بتوثيق ذلك لمن يعدّل القوالب في «مدير القوالب».
5. **النسخ والبحث في PDF:** نص PDF الناتج عن الطريقتين ليس مثالياً عند النسخ؛ لا يؤثر على الطباعة. ما يلزم البحث فيه يُخزَّن في قاعدة البيانات لا في PDF.
