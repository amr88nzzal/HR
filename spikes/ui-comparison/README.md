# مقارنة المكتبات: Mantine مقابل Ant Design

نفس الشاشة (قائمة الموظفين + فلاتر + منتقي تاريخ + جدول بتحديد + نافذة نموذج مع خطأ تحقق + أرقام ثلاثية الكسور) مبنية بالمكتبتين بـ RTL وخط Amiri. الصور في `shots/`.

```bash
cd mantine && npm i && npm run build      # أو antd
node shoot.mjs                             # يعيد توليد اللقطات (يحتاج Chromium)
```

الإصدارات المجرَّبة: Mantine `9.6.3` · Ant Design `6.6.5`.

## النتائج

| المعيار | Mantine | Ant Design |
|---|---|---|
| حجم الحزمة لهذه الشاشة وحدها (gzip) | **JS 157KB + CSS 38KB ≈ 195KB** | **JS 348KB** (CSS-in-JS يُحقَن وقت التشغيل) |
| RTL | `DirectionProvider` وخصائص منطقية؛ كل المكونات انعكست سليمة | `ConfigProvider direction="rtl"`؛ سليم |
| ترتيب النماذج | `Group grow` و`Stack` يعطيان محاذاة منتظمة بلا جهد | `Space` + `Form.Item` أنتج أعمدة غير متساوية؛ يحتاج `Row/Col` |
| منتقي التاريخ بالعربية | أشهر وأيام عربية، **بداية الأسبوع السبت**، عطل نهاية الأسبوع قابلة للضبط (`weekendDays`) | أشهر عربية وبداية السبت، لكن **أسماء الأيام الكاملة تتزاحم/تتداخل** في الرأس؛ بلا تلوين للعطلة |
| التقويم الهجري | غير مدعوم أصلاً (نعرضه بـ `Intl` كنص) | غير مدعوم أصلاً |
| الجدول | بسيط (نستخدم TanStack Table على أي حال) | غني (ترتيب، تحديد، تثبيت أعمدة…) لكننا سنبني الجدول بـ TanStack |
| النماذج | يتكامل مع React Hook Form مباشرة | `Form` خاص به؛ التكامل مع RHF أقل طبيعية |
| مكونات خاصة | لا شجرة هيكل جاهزة | `Tree` و`Transfer` و`Cascader` جاهزة |
| المظهر الليلي | مدمج (`colorScheme`) | عبر الخوارزميات `darkAlgorithm` |
| الترخيص | MIT | MIT |

## التوصية
**Mantine** (كما في التصميم الأصلي): أصغر بنحو النصف، وRTL أنظف، وتخطيط النماذج أسهل، ويتكامل مع React Hook Form وTanStack Table اللذين اعتمدناهما. ميزة Ant الرئيسية (الجدول والنموذج الغنيان) لا نحتاجها لأننا سنستخدم TanStack Table وReact Hook Form. ما ينقص Mantine (شجرة الهيكل التنظيمي) نسدّه بمكوّن `Tree` الموجود فيه أو مكتبة صغيرة.

## ملاحظات للتنفيذ
- ضبط `weekendDays` و`firstDayOfWeek` من إعدادات الشركة.
- أرقام الرواتب والتواريخ تُعرض داخل `dir="ltr"` (كما في اللقطات) للحفاظ على اتجاه الأرقام.
- التقويم الهجري: عرض نصي بـ `Intl` أولاً، والإدخال الهجري مرحلة لاحقة.
