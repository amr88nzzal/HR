# دليل المستخدم المختصر

## للموظف
- **الدخول:** بالبريد وكلمة المرور؛ الدعوة تصلك برابط لتعيين كلمة المرور.
- **الإجازات:** «إجازاتي ← طلب جديد»، اختر النوع والتواريخ، وتابع حالة الموافقة من الإشعارات.
- **الحضور:** راجع سجلك وقدّم طلب تصحيح عند الخطأ.
- **قسائم راتبي:** تظهر بعد قفل دورة الرواتب؛ الأرقام مخفية، اضغط «إظهار»، ويمكن تنزيل PDF.
- **الإشعارات:** من الجرس؛ ويمكن ربط تيليغرام من إعدادات الحساب.

## للمدير
- **صندوق الموافقات:** كل الطلبات المنتظرة منك؛ وافق أو ارفض مع ملاحظة، أو فوّض بديلاً أثناء غيابك.
- **فريقك:** تظهر لك بيانات فريقك فقط حسب نطاقك.

## لمدير الموارد البشرية
- **الموظفون:** إضافة وتعديل وإنهاء خدمة، والمرفقات والوثائق المنتهية.
- **الإجازات والحضور:** السياسات والأرصدة والاستيراد والتصحيحات.
- **الرواتب:** الإعداد ← دورة جديدة ← احتساب ← مراجعة («كيف حُسب؟») ← اعتماد ← قفل (ينشر القسائم) ← الدفعات.
- **الوثائق:** إصدار شهادات من القوالب بالترويسة.
- **التقارير:** اختر التقرير والمرشحات والأعمدة وصدّره؛ التصدير الكبير يعمل في الخلفية ويصلك رابط لمدة 24 ساعة.

## المساعدة
عند ظهور خطأ، أرسل رقم الطلب (`requestId`) الظاهر في رسالة الخطأ إلى مدير النظام.
