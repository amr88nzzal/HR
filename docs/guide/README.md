# الدليل المكتوب — كيف يُحرَّر ويُوسَّع

مقالات الدليل ملفات Markdown في `articles/`، وهي **المصدر الوحيد**: تُقرأ في المستودع وتُعرض داخل التطبيق في «دليل الاستخدام» (`/help`) بعد البناء. التعديل = تغيير ملف + طلب دمج، بلا أي كود.

## إضافة مقال
1. انسخ `TEMPLATE.md` إلى `articles/<رمز-المقال>.md` (الرمز لاتيني صغير بشرطات؛ هو معرّف الرابط `/help#رمز-المقال`).
2. املأ الترويسة ثم النص.
3. شغّل `pnpm --filter @hrms/web test` للتأكد أن المقال يُقرأ (اختبار الدليل يفحص الترويسات والروابط الداخلية).

## الترويسة
```
---
title: عنوان المقال
summary: سطر واحد يظهر تحت العنوان في القائمة
roles: employee, manager, hr, admin   # الأدوار المعنية (واحد أو أكثر)
order: 20                              # الترتيب داخل القائمة (الأصغر أولاً)
---
```
الأدوار: `employee` موظف، `manager` مدير، `hr` موارد بشرية، `admin` مدير النظام. المقال المشترك يذكر أكثر من دور.

## قواعد الكتابة
- **مهمة واحدة لكل مقال**، بعنوان فعل («طلب إجازة»، «قفل دورة الرواتب»).
- ابدأ بجملة «متى أحتاج هذا؟»، ثم **خطوات مرقّمة** بأسماء الشاشات والأزرار كما تظهر حرفياً في الواجهة.
- ضع **ملاحظات وتنبيهات** في النهاية (ما الذي لا يمكن التراجع عنه، ومن يرى ماذا).
- اربط المقالات ببعضها بـ `[نص](#رمز-مقال)`.
- لقطات الشاشة: ضع الملف في `images/` واكتب `![وصف](images/اسم.png)`. لا تضع بيانات حقيقية في اللقطات (استعمل بيانات `seed-demo`). لإعادة التقاطها كلها بعد تغيير الواجهة: `tools/guide-screenshots/capture.py` (التعليمات في رأس الملف؛ يحتاج نسخة محلية تعمل ببيانات `seed-demo` وPython مع Playwright).
- عند تغيّر شاشة أو زر، حدّث المقال في **نفس طلب الدمج** الذي غيّر الواجهة.

## الخطوة التالية: الفيديو
كل مقال يصلح سيناريو لفيديو عربي قصير (1–3 دقائق): العنوان = عنوان الفيديو، والخطوات = لقطات التسجيل. ستُضاف روابط الفيديو لاحقاً بسطر `فيديو: <رابط>` أعلى المقال.
