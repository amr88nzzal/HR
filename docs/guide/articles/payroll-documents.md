**متى أحتاج هذا؟** بعد احتساب الدورة أو اعتمادها، لإرسال الحوالات للبنك، وتوقيع الإدارة على الكشف، وتسجيل القيد في برنامج المحاسبة.

## الخطوات
1. افتح الدورة من «الرواتب ← دورات الرواتب» واضغط **مستندات الدورة**.
2. **كشف الإدارة للتوقيع (PDF):** جدول بكل موظف مجمّع حسب القسم مع مجاميع القسم والمجموع الكلي، وأسفله خانات «أعدّه / راجعه / اعتمده» بالتاريخ. متاح حتى في المسودة (يحمل وسم «مسودة»). نسخة Excel متاحة أيضاً.
3. **ملف تحويل البنك (Excel أو CSV):** بعد الاعتماد. يعرض أولاً عدد الحوالات وإجماليها والموظفين **بلا حساب بنكي** (لن يدخلوا الملف) ثم تؤكد التنزيل. الأعمدة: المستفيد، البنك، IBAN، المبلغ، العملة، المرجع. يشمل الدفعات المعلّقة فقط.
4. **قيد المحاسبة (Excel أو CSV):** بعد الاعتماد. قيد يومية متوازن: مدين بالاستحقاقات (حسب مركز التكلفة أو القسم) ودائن بالاستقطاعات وأقساط السلف وصافي الرواتب المستحقة.

## ربط الحسابات (مرة واحدة)
- «الرواتب ← إعداد الرواتب ← المكونات»: أدخل **رمز الحساب** لكل بند (مصروف للاستحقاق، التزام للاستقطاع، ولبند صاحب العمل حساب مصروف وحساب التزام مقابل).
- «الرواتب ← إعداد الرواتب ← الحسابات المحاسبية»: حسابات الشركة: الرواتب المستحقة، سلف الموظفين، والمصروف الافتراضي (للراتب الأساسي).
- أي بند بلا حساب يظهر في القيد بالرمز `UNMAPPED` مع تحذير قبل التنزيل.

## ملاحظات
- **IBAN كامل** في ملف البنك: يلزمه صلاحية «تصدير ملف تحويل الرواتب» ويُسجَّل كل تصدير في سجل التدقيق.
- الصلاحيات الجديدة تُمنح تلقائياً لمدير النظام؛ امنحها للأدوار الأخرى من شاشة الأدوار.
- الصيغة الحالية عامة (Excel/CSV)؛ صيغة بنك محدد أو SEPA يمكن إضافتها لاحقاً.
